# Команда ИИ-агентов собственника TSG

Тимлид (Claude Opus) и агенты Производство, Аккаунт, Бухгалтер работают с Битриксом только на чтение. Собственник общается с ними голосом или текстом в Telegram.

- **main.py** — точка входа Railway. `APP=bot` — бот; без неё — MCP-сервер, который при старте сам создаёт и обновляет агентов в Claude Platform.
- **tsg_bitrix/** — MCP-сервер: свой адрес на роль (`/<роль>/mcp`) и свой токен; деньги и персональные данные вырезаются по матрице `policy.py`; методы Битрикса только на чтение. `provision.py` — автонастройка агентов.
- **agents/** — промпты. Поменяли промпт, сделали push — после перезапуска сервиса агенты обновятся сами.
- **owner_bot/** — Telegram-бот: голос → Groq Whisper → Тимлид → ответ.
- **scripts/** — `ask.py` (вопрос из терминала), `inspect_fields.py` (какие поля видят роли), `setup_agents.py` (ручная настройка, обычно не нужна).

## Railway: один сервис

На пробном тарифе Railway лимит сервисов исчерпан, поэтому MCP-сервер и бот работают в одном сервисе `tsg-owner-agents` (домен `tsg-owner-agents-production.up.railway.app`, порт 8080).

Variables сервиса:
- `BITRIX_WEBHOOK_URL` — входящий вебхук Битрикса;
- `ANTHROPIC_API_KEY` — Console → Ключи API;
- `TELEGRAM_BOT_TOKEN` — от @BotFather;
- `TELEGRAM_ALLOWED_IDS` — ваш Telegram ID (узнать у @userinfobot);
- `GROQ_API_KEY` — распознавание голосовых;
- `SUMMARY_TIME=19:00` — вечерняя сводка (необязательно).

Порядок при старте: MCP-сервер → автонастройка агентов («автонастройка: агент TSG · Тимлид: …» в логах) → бот. Токены MCP вручную не нужны: оба конца вычисляют их из `ANTHROPIC_API_KEY` (HMAC, ключ из токена не восстановить). `APP=server` / `APP=bot` — запустить только одну часть, если позже разнесёте по двум сервисам.

Вебхук Битрикса: Разработчикам → Другое → Входящий вебхук под учёткой 239, права **CRM, Задачи, Пользователи, Структура компании, Чат и уведомления (im), Диск (disk)**. Сообщения и задачи уходят от имени владельца вебхука.

Проверить классификацию полей: `BITRIX_WEBHOOK_URL=... python scripts/inspect_fields.py` — ЗП, ФОТ, ОФ / НЕ ОФ должны быть `money`, ИИН и карты — `pii`. Ошибку правит переменная `FIELD_OVERRIDES`.

## Бот
- Отвечает только ID из `TELEGRAM_ALLOWED_IDS` (свой ID — у @userinfobot).
- Голосовое → показывает распознанный текст → «Принял, собираю…» → какие агенты подключились → ответ.
- Кнопки «Сводка за сегодня», «Что горит», «Новая тема». Одна сессия Тимлида на чат и день.
- `/voice` — ответ голосом (нужен `OPENAI_API_KEY`). `STT_PROVIDER=openai|yandex` — другие сервисы распознавания.
- Лимит расходов на сессию — `SESSION_BUDGET_CENTS` (по умолчанию 200 = 2 $).
